# Wireframes
PNG exports of the 12 wireframe boards (1200 px wide). Live canvas: https://claude.ai/artifact/PKvSj5oBUBEVbbg6wc4gcX
- Fonts in these PNGs fall back to system fonts; build with Source Serif 4 and Noto Sans as in spec §8.1.
- Data is sample data. `[placeholders]` mean the value is not decided yet.
- Main = style sample · Login · PMPools, PMPoolDetail, PMCreatePool, PMForms (Pool Manager) · FarmerHome, FarmerStatement · BuyerBrowse, BuyerPool, BuyerFlow (buyer) · Phone (390 px views).
- **Override (19 Nov):** in PMPools.png the tag "Closed · out of stock" on P-09 is replaced by "Out of stock" for an open pool with stock 0 (a closed pool shows "Closed"). See spec §4.5.
